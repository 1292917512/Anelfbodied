# 移动角色

`move` 控制桌宠本身在当前显示工作区可用范围内的位置，不控制系统鼠标或其他程序窗口。

```json
{ "action": "move", "x": 0.9, "y": 0.85, "durationMs": 800 }
```

`x`、`y` 是当前显示器工作区内 0–1 的归一化坐标：`x=0` 靠左、`x=1` 靠右，`y=0` 靠上、`y=1` 靠下。客户端按开始移动时角色的可见轮廓定位，透明留白不占边距，气泡独立避让边缘；这些值不是屏幕像素。用户跨屏拖动后，后续 `move` 使用新的显示器。`durationMs` 是整数，范围 100–10000，默认 1000 毫秒。

根据用户意图选择目标，例如“移到右下角”可以使用上面的值。没有截图能力或实时坐标查询，不能声称已避开某个应用按钮。协议没有显示器选择、相对移动、屏幕尺寸或坐标读取参数。

位置在移动完成后保留。用户拖动角色会取消正在执行的动作；如果需要结束同一任务中其他已排队批次，按[执行与恢复](execution.md)取消自己持有的 session。不要自动把角色拉回 AI 先前指定的位置。
